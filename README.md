# Sistema-de-Gestao-de-Oficina-Mecanica
Projeto final de Engenharia de Software II

### Pre-requisitos

- JDK 21 instalado
- IntelliJ IDEA (versão comunitária 2025.2)[https://www.jetbrains.com/idea/download/other/#releases-2025]
- Docker instalado e em execucao.
- Docker Compose.

no diretório raiz do projeto execute:

```bash
docker compose up -d
```
